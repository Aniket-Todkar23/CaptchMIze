🔑 Authentication

All API requests require authentication using an API key. You can obtain your API key by registering through our service.

API Key Registration

POST /api/register Content-Type: application/json { "email": "your@email.com", "name": "Your Name", "keyName": "My App Key" // optional }

Using Your API Key

Include your API key in requests using one of these methods:

Header (Recommended)

X-API-Key: your-api-key-here

Query Parameter

?api_key=your-api-key-here
🔒 Security Note: Never expose your API key in client-side code. Always make API calls from your backend server.

🌐 API Endpoints

POST Register for API Key

Endpoint: /api/register

Authentication: Not required

Parameter Type Required Description
email string Required Your email address
name string Required Your full name
keyName string Optional Custom name for your API key
Response (201 Created)
{ "success": true, "message": "API key generated successfully", "data": { "apiKey": "captcha_abc123def456...", "user": { "id": 1, "email": "your@email.com", "name": "Your Name" }, "rateLimit": "1000 requests per hour" } }

GET Generate CAPTCHA

Endpoint: /api/captcha/generate

Authentication: Required

Query Parameters

Parameter Type Required Description
type string Optional Specific CAPTCHA type (gif, image, text, math, puzzle)
Response (200 OK)
{ "success": true, "data": { "sessionId": "uuid-session-id", "type": "gif", "question": "What category does this GIF belong to?", "mediaUrl": "https://media.giphy.com/media/xyz/giphy.gif", "options": ["animals", "vehicles", "sports", "buildings"], "expiresIn": 10 // minutes } }

POST Verify CAPTCHA

Endpoint: /api/captcha/verify

Authentication: Required

Parameter Type Required Description
sessionId string Required Session ID from generate response
answer string Required User's answer to the CAPTCHA
Success Response (200 OK)
{ "success": true, "verified": true, "message": "Captcha verified successfully", "captchaType": "gif" }
Error Response (400 Bad Request)
{ "success": false, "verified": false, "message": "Incorrect answer", "code": "INCORRECT_ANSWER", "remainingAttempts": 2 }

GET Usage Statistics

Endpoint: /api/usage

Authentication: Required

Parameter Type Required Description
timeframe string Optional 1h, 24h, 7d, 30d (default: 24h)

🎭 CAPTCHA Types

Our API supports multiple CAPTCHA types to provide variety and enhanced security:

🎬 GIF CAPTCHA

Type: gif

Users identify the category of an animated GIF (animals, vehicles, sports, buildings, cartoons, actions).

// Example response { "type": "gif", "question": "What category does this GIF belong to?", "mediaUrl": "https://media.giphy.com/...", "options": ["animals", "vehicles", "sports", "buildings"] }

🖼️ IMAGE CAPTCHA

Type: image

Users identify the main subject of a static image.

// Example response { "type": "image", "question": "What is the main subject of this image?", "mediaUrl": "data:image/jpeg;base64,...", "options": ["animals", "vehicles", "sports", "buildings"] }

📝 TEXT CAPTCHA

Type: text

Users enter the text shown in a distorted image.

// Example response { "type": "text", "question": "Enter the text shown in the image", "mediaUrl": "data:image/png;base64,...", "inputType": "text" }

🧮 MATH CAPTCHA

Type: math

Users solve simple mathematical equations.

// Example response { "type": "math", "question": "What is 15 + 7?", "options": ["22", "21", "23", "20"] }

🧩 PUZZLE CAPTCHA

Type: puzzle

Users answer logical puzzles and reasoning questions.

// Example response { "type": "puzzle", "question": "Complete the sequence: 2, 4, 6, 8, ?", "options": ["9", "10", "11", "12"] }

🔧 Integration Guide

Step 1: Register for API Key

curl -X POST https://your-api.com/api/register \ -H "Content-Type: application/json" \ -d '{ "email": "developer@company.com", "name": "John Developer", "keyName": "Production API Key" }'

Step 2: Generate CAPTCHA

curl -X GET https://your-api.com/api/captcha/generate \ -H "X-API-Key: your-api-key"

Step 3: Present CAPTCHA to User

Display the CAPTCHA challenge to your user based on the type returned:

  • GIF/Image: Show the media and present multiple choice options
  • Text: Show the distorted text image and provide a text input
  • Math/Puzzle: Display the question and provide multiple choice options

Step 4: Verify Answer

curl -X POST https://your-api.com/api/captcha/verify \ -H "Content-Type: application/json" \ -H "X-API-Key: your-api-key" \ -d '{ "sessionId": "session-id-from-generate", "answer": "user-provided-answer" }'

Step 5: Handle Response

Based on the verification response, allow or deny user access to your application.

✅ Best Practice: Always validate CAPTCHA on your backend server before processing user actions.

💻 Code Examples

JavaScript/Node.js

const axios = require('axios'); class CaptchaAPI { constructor(apiKey) { this.apiKey = apiKey; this.baseURL = 'https://your-api.com/api'; } async generateCaptcha(type = null) { const params = type ? { type } : {}; const response = await axios.get(`${this.baseURL}/captcha/generate`, { headers: { 'X-API-Key': this.apiKey }, params }); return response.data.data; } async verifyCaptcha(sessionId, answer) { const response = await axios.post(`${this.baseURL}/captcha/verify`, { sessionId, answer }, { headers: { 'X-API-Key': this.apiKey, 'Content-Type': 'application/json' } }); return response.data; } } // Usage const captcha = new CaptchaAPI('your-api-key'); // Generate CAPTCHA const challenge = await captcha.generateCaptcha(); console.log('Challenge:', challenge); // Verify answer const result = await captcha.verifyCaptcha(challenge.sessionId, 'animals'); console.log('Verified:', result.verified);

Python

import requests class CaptchaAPI: def __init__(self, api_key): self.api_key = api_key self.base_url = 'https://your-api.com/api' self.headers = {'X-API-Key': api_key} def generate_captcha(self, captcha_type=None): params = {'type': captcha_type} if captcha_type else {} response = requests.get( f'{self.base_url}/captcha/generate', headers=self.headers, params=params ) return response.json()['data'] def verify_captcha(self, session_id, answer): response = requests.post( f'{self.base_url}/captcha/verify', headers={**self.headers, 'Content-Type': 'application/json'}, json={'sessionId': session_id, 'answer': answer} ) return response.json() # Usage captcha = CaptchaAPI('your-api-key') # Generate CAPTCHA challenge = captcha.generate_captcha() print(f"Challenge type: {challenge['type']}") # Verify answer result = captcha.verify_captcha(challenge['sessionId'], 'animals') print(f"Verified: {result['verified']}")

PHP

<?php class CaptchaAPI { private $apiKey; private $baseUrl = 'https://your-api.com/api'; public function __construct($apiKey) { $this->apiKey = $apiKey; } public function generateCaptcha($type = null) { $url = $this->baseUrl . '/captcha/generate'; if ($type) { $url .= '?type=' . urlencode($type); } $response = file_get_contents($url, false, stream_context_create([ 'http' => [ 'header' => 'X-API-Key: ' . $this->apiKey ] ])); return json_decode($response, true)['data']; } public function verifyCaptcha($sessionId, $answer) { $data = json_encode([ 'sessionId' => $sessionId, 'answer' => $answer ]); $response = file_get_contents($this->baseUrl . '/captcha/verify', false, stream_context_create([ 'http' => [ 'method' => 'POST', 'header' => 'X-API-Key: ' . $this->apiKey . "\r\n" . 'Content-Type: application/json', 'content' => $data ] ]) ); return json_decode($response, true); } } // Usage $captcha = new CaptchaAPI('your-api-key'); // Generate CAPTCHA $challenge = $captcha->generateCaptcha(); echo "Challenge type: " . $challenge['type'] . "\n"; // Verify answer $result = $captcha->verifyCaptcha($challenge['sessionId'], 'animals'); echo "Verified: " . ($result['verified'] ? 'true' : 'false') . "\n"; ?>
